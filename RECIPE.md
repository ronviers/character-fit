# RECIPE

The whole process. Two cards. Reinvent everything else, per substrate.

## THE STEPS — fit character into a substrate

1. **Reduce it.** Smallest structure that could carry the signature — a
   generator, a kernel, a `(C, χ)` pair. One file, hardcoded — including the
   measured numbers and where they came from. External sources rot (an SI
   returns 403, a link dies); the number you used lives in the script.
2. **Seal the answer first.** Write what the framework *should* read, before you
   fit. Don't peek.
3. **Run the reads.** minted? protected? sustained?  (or: place / scale /
   FDR-bend / X.) One function. No branching.
4. **Make one picture.**
5. **Compare to the seal.** MATCH / MISS / KILL.
6. **One result file. Next substrate.**

## THE TRAPS — each one cost a session

- **χ must EMERGE from one honest process, never be assembled by hand.** Don't
  set `χ = (C₀−C)/T` by fiat — the FDR read goes tautological and tests nothing.
  Equally, don't build `C` and `χ` from separate ad-hoc choices — they then fit
  no real operating point and the test fails for the wrong reason. `C` and `χ`
  are two measurements on *one* generating process; let FDT / X agree or break on
  its own.
- **Ground truth is analytic, independent, and you know its error budget.** The
  thing you check against is never produced by the same code doing the fit — you
  are the examinee, never the answer key. And if the reference is itself a proxy
  (an analytical locus standing in for the real ensemble), its error bounds every
  verdict: an exact closed form beats a fast approximation.
- **A fit hands you a confident number for a parameter the data can't see.** A
  single-mode FDR locus pins `chit` but leaves `γ_AB` rank-deficient; a 1-param
  inversion can't recover the FDT-violation X at all. The round-trip then
  *passes* while that axis was never tested — the worst false pass. Before you
  trust a read, confirm the observable actually constrains it: read an
  unconstrained fingerprint at the rawest layer that shows it, or mark it
  unconstrained and report no value. Every quantity you claim to read needs an
  observable that pins it.
- **A NaN or a boundary value is a tripwire.** Diagnose it — don't fill it. Never
  clip a state variable to 0; that manufactures the answer. The framework lives
  in the open interval; the boundary is the failure.
- **Sweep the camera (τ_obs) first.** If the invariant migrates as you move the
  observation window, KILL — you're reading the camera, not the substrate.
- **A KILL is a falsifier, not a bug.** Write it down and stop. A clean failure
  is worth more than a weak pass.
