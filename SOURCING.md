# SOURCING — net a real substrate from the outbound channel

The RECIPE assumes you already hold a substrate and its numbers. For a *real,
measured* substrate, getting there is its own move — this is the template for it,
distilled from the three-ask arc that landed DNA-NESS. (Worked example, frozen:
`mpa-atlas/docs/gate2_measured_matrix_prompt.md` +
`emergent_identity_substrate_prompt.md`.)

It took **three asks**. Expect to iterate; sharpen each ask against what the last
return got wrong.

## The arc

1. **Screen by the discriminator.** Name the *one* property that separates your
   target from its look-alikes (DNA: protection = the affinity **sign**, not a
   Chern / EP / band invariant). State the look-alikes as **HARD EXCLUSIONS**, each
   with the rejected lead, so the channel can't re-suggest them. Name the positive
   target *shape* (finite-D, far-from-EP, internal cycle).
2. **Demand instanceable structure, not analogy.** For each candidate require the
   explicit rate / coupling matrix (or a minimal model that yields one), evidence
   the parts are unprotected and the union frustrated, and the run-loop test.
   *A real matrix you can run beats a qualitative analogy.*
3. **Then narrow to DATA.** Once the class is right, the decisive ask: *"We do not
   need another model. We need a PUBLISHED, MEASURED rate matrix."* Require numeric
   rates with units **and the exact table / figure / SI location**, the two-module
   decomposition, the physically-named drive, and the DOI.

## Forbid (every ask)

- **No invented or back-filled numbers.** A partial real scheme with its gaps named
  beats a complete fake — *do not invent rate constants to complete a matrix.*
- **No self-graded verdicts.** You instance the numbers yourself; the gate is
  discharged by *running* the matrix, never by citation or a model's self-reported
  PASS. (A past return hardcoded its own run-loop and exclusion tests to PASS and
  mis-stated its affinity — the channel's verdict is worth nothing; only numbers you
  run are. This is THE TRAPS: *you are the examinee, never the answer key.*)
- **No analogies, no excluded classes** (Chern / EP / lattice / physical rotation).

## Do the recon yourself first

Name the leads you already found and the **specific gap** in each (which rates are
published, which are missing, whether an SI or follow-up fills it), so the channel
*closes the named gap* instead of re-finding the papers. That is what turned a
"right class, no data" return into a runnable real instance.

A substrate is sourced — ready to queue in `HANDOFF.md` — only once its numbers are
**in hand and in the script**. External sources rot (the DNA-NESS SI returned 403).
